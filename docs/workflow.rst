Workflow
========

Entry point
-----------

- Snakemake entry file: ``workflow/Snakefile``
- Config: ``config/config.yaml``

Guarantees and determinism
--------------------------

- ``metadata.tsv`` is generated by aligning IPU annotations within a fixed
  temporal window; each row corresponds to one anchor IPU with partner features
  and latency.
- The TRF workflow is subject-level and run-wise. For each available run, it
  loads filtered EEG (``*_raw_filt.fif``), the downsampling timing sidecar
  (``*_raw_ds_timing.json``), and the configured predictor files from
  ``features/continuous`` and ``features/events``.
- EEG is cropped to the conversation window using
  ``conversation_start_seconds`` from the timing sidecar, then resampled to the
  configured TRF rate (currently ``64 Hz`` by default).
- Predictors are aligned onto the same time base. Continuous predictors are
  resampled, while event predictors are rasterized into sample-space impulse or
  valued regressors. Supported predictor families include self/other speech
  envelope, F0, vowel formants, phoneme/syllable/token onsets, function/content
  word onsets, and LM-derived surprisal/entropy.
- Each cropped run is split into contiguous within-run blocks (currently 4 per
  run by default). Blocks that are too short to support the requested lag window
  are skipped before model fitting.
- The design matrix is built separately for each segment with a lag window
  defined in ``config/trf.yaml``. The current config uses a forward model with
  lags from ``-0.20`` to ``1.0`` seconds.
- Model fitting uses nested grouped cross-validation with ridge regression via
  SpyEEG's ``TRFEstimator``. Outer folds are grouped by run, inner folds are
  grouped by segment, and the ridge ``alpha`` is selected from a log-spaced
  grid on inner-fold performance before being refit and scored on held-out outer
  folds.
- The primary score is the mean channel-wise Pearson correlation between held-out
  EEG and TRF predictions. Subject-level outputs are written under the configured
  output root as ``trf/<subject>/task-<task>/`` with fold scores, selected
  alphas, fold coefficients, and design metadata.
- TRF QC adds two complementary checks. EEG QC compares the real model against a
  circularly shifted null built by shifting envelope predictors independently
  within each run. Feature QC recomputes the model after ablating configured
  predictor groups and records the score drop relative to the full model.
- Report generation consumes these outputs to make per-subject alpha-sweep
  summaries, group-average TRF kernel manifests, a TRF score summary figure, and
  a multi-panel TRF main figure.
- Outputs are deterministic given identical inputs, config, and software
  environment.
- To regenerate the full DAG, run Snakemake from the repository root with
  ``-s workflow/Snakefile`` and the desired target.
